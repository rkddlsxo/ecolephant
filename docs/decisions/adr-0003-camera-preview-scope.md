# ADR-0003 · 모델 연결을 보류한 카메라 미리보기

- 날짜: 2026-10-17
- 상태: 이전 사용자 요청 반영. 2026-11-01 합성 테스트 범위로 확장.
- 관련: DEC-001, DEC-002, DEC-008, DEC-010.

## 사용자 지정 범위

사용자는 사전 학습된 자세 측정 AI 모델을 가져올 예정이며, 그 부분은 비우고 웹캠을 켜는 단계까지만 요청했습니다.
따라서 특정 모델·SDK·가중치는 선택하거나 설치하지 않습니다.
실제 카메라 미리보기를 기본 화면에 두고 측정·판정·알림·세션 생성은 연결하지 않습니다.

## 구현 경계

frontend의 useWebcam이 getUserMedia와 MediaStream 정리를 맡습니다.
model-adapter는 null로 유지하며, 구현하지 않은 측정을 합성 신호로 대체 실행하지 않습니다.
기존 데모 분석·API·기록 코드는 후속 연결 재료로 보관합니다.
이 결정은 실제 자세 지표의 정확도나 제품 출시 승인으로 해석하지 않습니다.

## 2026-11-01 범위 확장

사용자는 모델 연결을 보류하면서 백엔드와 간결한 프론트 기능을 요청했습니다.
카메라 미리보기는 유지하고 별도 합성 테스트로 API·기록을 확인합니다.
실제 영상에서 추론하지 않으며 [ML 인계](../measurement/ml-handoff.md)의 계약은 협업 초안입니다.
