# 미확정 결정과 검증 항목

운영 출시 결정은 **대기**이며, 사용자 지정 스택과 로컬 데모 선택은 ADR-0002에 기록했습니다. 아래 후보는 작성 시 제안이며 승인 결과가 아닙니다. 결정자는 팀에서 지정하고 선택·근거·날짜·영향 계약을 기록합니다.

| ID | 항목 | 현재 후보 | 필요한 근거 | 해결 시점 |
|---|---|---|---|---|
| DEC-001 | 첫 출시의 센서 범위 | 웹캠만 먼저 출시하거나 세 방식 모두 포함 | 클라이언트 플랫폼과 도우미 개발 가능 여부 확인 | 출시 범위 고정 전 |
| DEC-002 | 웹캠 특징에서 각도로의 매핑 | 특징은 유지, 도 단위 출력은 실측 전 비활성 | 측면 기준 측정과 사용자별 오차·분류 성능 | 각도 기반 판정 구현 전 |
| DEC-003 | AirPods 호환성·축·도우미 보안 | 루프백 인증·시계 정렬·플랫폼별 검증 | OS/모델/API 축과 브라우저 연결 실험 | AirPods 통합 전 |
| DEC-004 | 결합 표의 빈 구간과 상태 이름 | 판정과 참고 종합값 분리, AirPods 한계 표기 | 상충 센서·경계값 사용자 시나리오 합의 | 판정 프로필 승인 전 |
| DEC-005 | 인증과 기록 소유자 | API는 소유자 문맥을 요구, 발급 방식은 미정 | 로그인/익명/기기 동기화와 배포 범위 결정 | 외부 접근 가능한 API 공개 전 |
| DEC-006 | 기록 보관과 삭제 | 세션별 삭제, 기간은 공개 전 확정 | 운영·백업·동의 계획 | 실사용 데이터 저장 전 |
| DEC-007 | 보정·품질·알림 수치와 자동 감소 | 예시 정책의 수치는 초기 실험값 | 임계·지속·쿨다운·안정 편차·복구 시험 | 정책 release_approved 전 |
| DEC-008 | 기술 스택과 배포 | Flask·React·TS5.9·Vite8·Node22 반영. SQLite는 로컬 데모 선택, 운영 DB·호스팅은 대기 | [ADR-0002](adr-0002-first-mvp-stack.md), 계정·호스팅·보안 리뷰 | 운영 통합 전 |
| DEC-009 | kg 환산과 연구 근거 표시 | kg 카드 기본 보류, 원문 서지 검증 | 원논문 대조·모델 의미·문구 검토 | 대외 화면·발표 전 |
| DEC-010 | 탭 중단과 미완료 세션 처리 | 무효 창·제한된 메모리 큐·미완료 표시 | 백그라운드/절전/종료/재연결 실험 | 신뢰성 완료 판정 전 |

합의가 끝나면 [결정 템플릿](../../harness/docs/templates/decision.md)으로 기록하고 해당 항목을 연결합니다. 정책 변경은 새 정책 ID를 만들고 기존 세션 해석을 덮어쓰지 않습니다. 새 결정 기록을 추가할 때 [문서 색인](../index.md)과 [추적표](../../harness/metadata/traceability.json)도 갱신합니다.

로컬 데모 범위를 운영 출시 승인으로 확장하지 않습니다. DEC-001/002/003/005/006/007/010의 실제 장치·정책·보관·로그인 검증은 남아 있습니다.
