# 현재 구현 현황

기준일: 2026-11-01. 실제 자세 모델은 미연결이며, 합성 입력은 테스트로 표시합니다.

## 구현 범위

| 영역 | 현재 동작 | 위치 |
|---|---|---|
| 카메라 | 권한 요청·미리보기·켜기·끄기·좌우 반전과 스트림 정리 | [카메라 훅](../../frontend/src/features/camera/useWebcam.ts) |
| 테스트 측정 | 합성 입력의 시작·일시정지·재설정·종료·알림·저장 | [측정 화면](../../frontend/src/pages/MeasurePage.tsx) |
| 백엔드 | Flask 세션·결과·이벤트·기록·통계 API와 SQLite 저장 | [백엔드](../../backend/README.md) |
| 정책 | 세션별 기준 보존·버전 충돌 차단·과거 초안 호환 | [데이터 모델](../data/model.md) |
| 인증 | 로컬 토큰과 선택형 Cognito 로그인·복구 | [인증 안내](authentication.md) |
| 인계 | 모델 연결 형식과 ML 담당 작업 | [ML 인계](../measurement/ml-handoff.md) |
| 하네스 | 백엔드 계약·정책·보안 검사와 API 실행 테스트 | [품질 게이트](../../backend/harness/docs/quality/gates.md) |

카메라 미리보기는 실제 모델을 실행하지 않습니다. 테스트 결과는 `data_source=demo`입니다.
`real` 저장은 승인된 정책과 카메라 매핑을 요구합니다. 현재 정책은 미승인이고 실측 흐름은 미연결입니다.
테스트와 실측 통계는 출처별로 분리하도록 계약과 집계를 준비했습니다.
영상·관절점·원시 모션은 백엔드에 보내지 않습니다. 원본 미전송의 실네트워크 검증은 별도입니다.

## 남은 작업

- 실제 포즈 모델·특징 추출·보정·매핑과 정확도 검증, 승인된 정책 버전 등록 및 실측 연결.
- 새 정책의 프론트 전달과 긴급 철회·진행 중 세션 처리 정책 결정.
- AirPods 도우미·연결 보안·축·호환성·시계 정렬.
- 실제 Cognito 계정·MFA 등록·보관 정책·운영 속도 제한·AWS/DynamoDB 배포 및 실제 환경 검증.
- 프론트 담당자의 상세 UI/UX와 실제 모델 통합.
- 브라우저 강제 종료 뒤 메모리 대기열의 복구 방법과 보관 정책 결정.
- 진행 중인 세션을 다른 탭이나 기기에서 삭제하지 않도록 협의할 처리 방식.
- 비정렬 타임라인·이전 기록·통계와 일부 재시도·이벤트 저장은 전체 결과를 읽습니다. 실제 AWS 규모의 성능·비용 검증이 필요합니다.

## 검사

실행 명령은 [로컬 실행](local.md), 인수 범위는 [인수 시나리오](../quality/acceptance.md)를 따릅니다.
2026-11-01 Windows 로컬에서 SQLite·DynamoDB Local 백엔드 정규 검사 178개 중 177개가 통과했습니다.
이후 프론트 검사 102개, 빌드·코드 형식·API 계약 확인이 통과했습니다.
백엔드 정규 검사 191개 중 SQLite 등 96개가 통과했고, DynamoDB Local과 선택형 장시간 검사 등 95개는 이번에 건너뛰었습니다.
Windows의 별도 복사본에서 Node 22·Python 3.13으로 새 설치와 합성 측정 저장·조회, 기본 직접 연결과 설정 충돌 복구를 확인했습니다.
정규 검사에서 건너뛰는 8시간 합성 저장 검사는 별도로 실행해 통과했습니다.
API 응답 형식, 카메라 모의 권한·종료, 측정 재시도와 모델 출력 형식을 확인했습니다.
카메라 트랙의 연결 종료·재생 지연·숨김 상태와 늦은 권한 응답은 모의 장치로 확인했습니다.
가상의 잘못된 HTTP API 주소는 배포 빌드에서 로그인 전에 차단되는 것을 브라우저에서 확인했습니다.
시험용 서명 키로 Cognito 토큰 검증과 사용자별 기록 분리를 확인했습니다. 실제 계정 검증은 아닙니다.
브라우저에서 합성 측정의 시작·일시정지·종료·저장과 기록 조회를 확인했습니다.
별도 합성 세션으로 최신순 목록과 같은 탭에서 측정 중 삭제 차단·종료 후 삭제 활성화를 확인했습니다.
합성 세션을 다른 탭에서 삭제해 경고·저장 중단·미승인 결과 유지와 명시적 정리 후 재시작을 확인했습니다.
합성 세션 두 건을 Flask에 저장해 오늘·일별·시간별 통계와 화면 수치가 일치하는지 브라우저에서 확인했습니다.
서울 자정 전후와 탭 복귀, 분모가 0인 통계·방식별 미분류 처리는 모의 프론트 검사로 확인했습니다.
페이지 조회 실패 후 기존 결과 유지·재시도는 모의 프론트 검사로 확인했습니다.
불완전한 서버 확인·중복 재시도·동시 종료·화면 갱신 실패와 오프라인 큐 한도에서의 일시정지를 합성 검사로 확인했습니다.
합성 이벤트 121건의 여러 페이지 조회를 브라우저에서 확인했습니다. 다운로드 파일 자체는 브라우저에서 확인하지 않았습니다.
24시간을 넘도록 구성한 희소 합성 기록은 브라우저에서 타임라인 구간을 차례대로 불러왔습니다.
여러 페이지 내보내기·중간 실패·화면 이탈과 계정 전환 중 늦은 응답·재시도는 모의 프론트 검사로 확인했습니다.
밀리초·현지 자정·서머타임·측정 종료 알림 경계와 무관한 세션의 반복 계산을 합성 데이터로 검사했습니다.
시작·종료·기간 조회의 밀리초 미만 입력 거부와, 정밀도에 영향을 주지 않는 끝자리 0 허용을 확인했습니다.
합성 8시간 기록을 5초 배치로 저장해 재시도·알림 16건·집계를 확인했습니다. SQLite에서 전체 결과 읽기는 18회였습니다.
해당 기록의 분별 요약 480개와 마지막 2시간 타임라인을 확인했습니다. 별도 로컬 비교에서 원본 조회 약 112ms, 요약 조회 약 3ms였고 응답은 같았습니다.
선택형 로그인 화면과 인증 전 차단을 브라우저에서 확인했고 인증 SDK는 모의 객체로 검사했습니다.
임시 토큰으로 배포 빌드 유출 검사가 통과했습니다. 운영 의존성 취약점 검사는 0건입니다.
개발 도구 의존성에는 보통 등급 경고 14건이 남아 있어 도구 교체·업데이트 검토가 필요합니다.
실제 카메라 권한·영상, AirPods 장치, 클라우드와 운영 인증은 이번에 검증하지 않았습니다.
DynamoDB Local 1.25.1과 3.3.2는 메모리 테스트만 수행했습니다. Docker Compose와 실제 AWS는 별도 검증이 필요합니다.
합성 정책으로 기준·가중치·알림·통계 분리, 과거 세션 호환과 동일 ID 동시 등록 충돌을 확인했습니다.
백엔드 검사에 Lambda HTTP API 가상 요청 3개가 포함됩니다. CDK 템플릿 검사 3개는 실제 배포 검증이 아닙니다.
인증 만료·계정 전환 시 측정 상태 격리와 DynamoDB 부분 삭제 후 타인 식별자 보존을 합성 데이터로 확인했습니다.
패키징 검사 4개와 Python 3.12 Linux용 패키지 생성, 해당 패키지를 포함한 CDK Python 앱의 로컬 구성을 확인했습니다.
Linux 실행과 실제 계정의 권한·네트워크·배포는 확인하지 않았습니다.
합성 입력 검사는 실제 센서 정확도·임상 진단·운영 출시를 증명하지 않습니다.
