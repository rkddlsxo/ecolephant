# 현재 구현 현황

기준일: 2026-10-17 · 최신 요청: **AI 모델 연결은 비우고 카메라를 켜는 단계까지만**.

## 이번 단계에서 구현한 부분

| 영역 | 내용 | 위치 |
|---|---|---|
| 기본 화면 | 실제 웹캠을 중심으로 한 준비 화면 | [준비 화면](../../frontend/src/pages/PreparePage.tsx) |
| 영상 | 권한 요청·실시간 표시·켜기·끄기·좌우 반전·실제 해상도 표시 | [미리보기](../../frontend/src/components/CameraPreview.tsx) |
| 수명주기 | 이탈·탭 비활성화·pagehide·장치 종료·늦은 권한 응답 정리 | [웹캠 훅](../../frontend/src/features/camera/useWebcam.ts) |
| 오류 | 권한 거부·장치 없음·접근 실패·지원 환경 안내·재시도 | [웹캠 훅](../../frontend/src/features/camera/useWebcam.ts) |
| 모델 자리 | 어댑터 null, 측정 버튼 비활성, 준비 중 화면 | [모델 경계](../../frontend/src/features/measurement/model-adapter.ts), [측정 화면](../../frontend/src/pages/MeasurePage.tsx) |

영상·사진·음성 저장, 프레임 읽기·AI 추론, 영상 업로드 코드를 이 미리보기에서 실행하지 않습니다.
카메라 준비 화면은 백엔드 연결 없이도 사용할 수 있습니다.

## 기존에 작성해 둔 코드

- Flask 12개 HTTP 동작, SQLite 저장·조회·삭제·집계.
- 합성 신호 판정·화면 알림·전송 큐·기록 상세·내보내기.
- 사용자 지정 프론트 스택, 문서·OpenAPI·하네스·개발 도구.
- DynamoDB·CDK·Compose·Amplify 초안.

기존 합성 측정은 현재 카메라 화면과 연결하지 않았습니다. 기존 저장된 예시 기록만 기록 화면에서 조회할 수 있습니다.

## 아직 연결하지 않은 부분

1. 사용자가 가져올 자세 측정 AI 모델과 모델 추론.
2. 실제 자세 지표·기준 보정·정확도 검증·측정·알림·저장 흐름.
3. AirPods 모션 도우미·축·호환성·페어링.
4. 운영 로그인·AWS 배포·디자인 시스템 패키지.
5. 기존 API·집계·오프라인 동작의 제품 통합 검증.
