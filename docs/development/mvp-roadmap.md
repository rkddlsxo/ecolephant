# MVP 구현 순서와 완료 게이트

아래는 초기 구현 순서와 완료 증거를 정리한 계획입니다. 실제 진행 상태는 [현재 구현 현황](mvp-status.md)과 결정 기록을 따릅니다.

| 단계 | 결과 | 선행 결정 | 완료 증거 |
|---|---|---|---|
| M0 범위·기술 합의 | 출시 모드, 인증, 스택, 역할·소유자 결정 | DEC-001/005/006/008 | 선택과 근거가 있는 결정 기록 |
| M1 합성 화면 | 준비·측정·기록 화면, 무효·오류 상태, 모의 API | 상태·계약 검토 | AC-001/002/012와 계약 fixture |
| M2 웹캠 신호 | 장치·랜드마크·보정·품질·시계 | DEC-002/007 | 특징·매핑 실측, AC-003/004/008/009/011 |
| M3 판정·알림 | 순수 분석 모듈, 전체 결합 표, 시간 규칙 | DEC-004/007 | 합성 경계·지속·교정 AC-010/015~018 |
| M4 서버 기록 | 소유권·배치·종료·조회·삭제·집계 | DEC-005/006/008 | AC-019~026, 네트워크 원본 미전송 |
| M5 AirPods 선택 범위 | 도우미·보안·시간 정렬·전환 | DEC-001/003 | 지원 기기 표, AC-005~007/027/028 |
| M6 통합·실사용 검증 | 신뢰성·성능·정확도·문구 | DEC-007/009/010 | 적용 대상 AC 전체와 실측 결과 |

M1은 합성 화면에 한하며 실제 측정이라고 표시하지 않습니다. M2의 매핑이 검증되기 전 웹캠 도 단위 판정을 제품 기능으로 완료 처리하지 않습니다. DEC-001에서 세 모드를 모두 포함하면 M5도 필수입니다.

## 시작할 작업

- [ ] DEC-001 출시 센서 범위를 정합니다.
- [ ] DEC-008 언어·프레임워크·DB·배포 구성을 정합니다.
- [ ] DEC-005 기록 소유권과 인증 발급 방식을 정합니다.
- [ ] DEC-002 기준 측정과 웹캠 매핑 실험을 계획합니다.
- [ ] 담당·일정·완료 증거를 붙인 첫 작업 계획을 만듭니다.
