# 카메라 미리보기

## 사용 순서

1. 준비 화면에서 **켜기**를 누릅니다.
2. 브라우저 권한 창에서 카메라 사용을 허용합니다.
3. 현재 영상과 연결 상태를 확인합니다. **좌우 반전**은 표시 방향만 바꿉니다.
4. **끄기**로 연결을 해제합니다.

허용 대기 중에는 **요청 취소**를 사용할 수 있습니다. 이미 열린 브라우저 권한 창은 직접 닫아야 합니다.
취소·페이지 이탈 뒤 권한 요청이 늦게 완료되면 받은 스트림을 즉시 해제합니다.
페이지 이동, 탭 비활성화, pagehide, 장치의 ended 이벤트에도 카메라를 정리합니다.
이미 종료된 트랙이나 재생 중 연결이 끊긴 장치는 켜짐으로 표시하지 않고 오류와 재시도를 제공합니다.
권한이나 재생 대기 중 탭이 숨겨져도 스트림과 대기 상태를 정리합니다.
자동으로 다시 켜지지 않으며 사용자가 다시 버튼을 눌러야 합니다.

## 오류 안내

- 권한 거부: 주소창의 사이트 권한에서 카메라를 허용한 뒤 다시 누릅니다.
- 장치 없음: 카메라 연결과 브라우저에서 사용할 수 있는지 확인합니다.
- 장치 사용 중: 다른 앱의 카메라 사용을 종료한 뒤 다시 누릅니다.
- 지원 환경: localhost 또는 HTTPS에서 카메라 API를 지원하는 브라우저가 필요합니다.

## 모델 연결 자리

[model-adapter.ts](../../frontend/src/features/measurement/model-adapter.ts)의 어댑터는 `null`입니다.
사용자가 모델을 선택하면 이 경계에서 로딩·프레임 분석·해제를 연결합니다.
현재는 모델·WASM·가중치를 추가하거나 다운로드하지 않습니다.
카메라 화면은 영상만 표시합니다. 별도의 테스트 측정은 합성 입력으로 API에 기록합니다.
마이크는 요청하지 않습니다. [ML 인계](../measurement/ml-handoff.md)를 참고하세요.

## 검증 상태

빌드·린트 결과는 [상태 보고서](mvp-status.md)에 기록합니다.
실제 사용자 카메라 권한 허용·장치 동작·브라우저 시나리오는 자동으로 실행하지 않았습니다.
