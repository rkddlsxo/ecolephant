# 영상 개인정보와 통신 보안

## 전송 허용 목록

브라우저는 웹캠 프레임·사진·영상·관절점 좌표·로컬 보정 기준·원시 IMU를 서버에 보내지 않습니다. API는 명시된 파생 결과와 메타데이터만 받으며 알 수 없는 필드를 거부합니다. 오류·분석 SDK·크래시 로그·콘솔 덤프에도 원시 입력을 넣지 않습니다.

화면 캡처·녹화·원본 데이터 수집이 필요한 검증 실험은 일상 사용과 분리하고 별도 동의·보관·삭제 계획을 둡니다. 이 저장소의 PDF UI 시안에는 실측 사용자 데이터가 없습니다.

## 권한과 소유권

카메라·모션·알림 권한은 사용 이유와 함께 사용자 동작으로 요청합니다. 동의 철회 시 해당 장치와 버퍼를 해제합니다. 카메라가 꺼진 모드에서 캡처를 계속하지 않습니다.

API는 인증된 소유자 문맥으로 세션을 제한합니다. 다른 소유자 세션 조회는 404로 응답합니다. 삭제는 존재 여부를 노출하지 않는 204 정책을 사용하며 타인 데이터는 보존합니다. 토큰·소유자 생성·보관·갱신은 DEC-005 결정 대기이며 공용 토큰을 실제 제품 인증으로 사용하지 않습니다. 요청 크기 제한과 요청별 검증을 구현했습니다. 운영 HTTPS·속도 제한·허용 Origin·CSRF 정책은 배포 설정과 함께 검증해야 합니다.

선택형 Cognito 경로는 액세스·갱신 토큰을 메모리에만 둡니다. SDK의 로그인 중간 상태는 세션 저장소를 사용할 수 있습니다.
실제 사용자 풀과 보안 설정 검증, 운영 보관 정책은 아직 완료되지 않았습니다. [설정과 한계](../development/authentication.md)를 따릅니다.

## 로컬 도우미

루프백 주소만 사용하고 전체 네트워크 인터페이스에 공개하지 않습니다. Origin allowlist, 짧게 유지하는 페어링 자격, 첫 메시지 인증, 재연결 시 인증을 적용합니다. 토큰을 URL·서버 로그·브라우저 기록에 넣지 않습니다. 허용하지 않은 웹 Origin과 인증 전 모션 구독은 거부합니다.

HTTPS 페이지에서 로컬 도우미에 연결할 수 있는 브라우저·인증서·권한 조건은 실제 환경에서 검증해야 합니다. 우회 플래그·보안 비활성화를 사용자 절차로 만들지 않습니다.

## 삭제와 보관

세션 삭제 시 원본 결과, 이벤트, 집계 캐시를 함께 제거합니다. 사용자에게 보관 기간과 기기 간 연동 범위를 안내합니다. 구체 기간과 백업 정책은 DEC-006 해결 후 공개합니다. 정책 미정 상태로 영구 보관을 기본값으로 구현하지 않습니다.

## 검증

네트워크 캡처로 허용 필드만 전송되는지, unknown 필드가 422로 거부되는지, 타인 세션 조회·삭제가 불가능한지, 도우미가 비허용 Origin을 거부하는지 확인합니다. 문서·스키마 검사는 이 실제 실행 검증을 대체하지 않습니다.
