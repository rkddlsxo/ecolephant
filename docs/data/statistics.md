# 시간과 자세 기록의 집계 정의

아래 계산은 설계 제안입니다. 모든 비율은 샘플 개수가 아닌 창의 duration_ms로 가중합니다. 시간 구간은 `[시작, 끝)`으로 계산하고 조회 경계에 걸친 창은 겹친 시간만 반영합니다.

밀리초 경계의 겹친 시간은 부동소수점 초가 아닌 정수 밀리초로 계산합니다.

## 유효성과 비교 그룹

`quality=valid`이며 센서별 각도·모드·정책이 일치하는 창만 각도·자세 분모에 포함합니다. 무효·일시정지·재보정은 정상 시간에 넣지 않습니다. `active_mode + policy_id`별로 집계하고 서로 다른 그룹의 평균·비율을 하나의 동일 측정값처럼 합치지 않습니다. 혼합 세션은 그룹별 summary를 반환합니다.

| 지표 | 계산·표시 |
|---|---|
| 전체 경과 시간 | 종료 시각-시작 시각. 자세 유효 시간과 구분 |
| 유효 측정 시간 | 유효 창 duration_ms 합 |
| 평균 참고 각도 | sum(display_angle_deg × 유효 ms) / 유효 ms. 분모 0이면 null |
| 기준 범위 비율 | normal 시간 / 유효 시간 × 100. 분모 0이면 null |
| 주의 자세 시간 | caution과 high 시간의 합. 알림 인정 최소 시간과 무관 |
| 높은 신호 시간 | high 시간의 합. AirPods의 경우 ‘고개 숙임 시간’으로 표기 |
| 거북목 의심 시간 | reason이 combined_high 또는 forward_shift인 high 시간. head_flexion만인 구간은 제외 |
| 시간대별 비율 | 해당 시간대·동일 그룹의 높은 신호 시간 / 유효 시간 × 100 |
| 알림 수 | alert_id별 전달된 1차 1회. 2차·채널 수·실패 시도는 별도 지표 |
| 교정 소요 시간 | 전달된 첫 1차 시각부터 같은 alert_id의 교정 시작 시각까지. 미확인 표본 제외 |

## 최근 30분과 기록 차트

1분 버킷마다 normal/caution/high/unknown 시간을 함께 반환합니다. 상태 대표색은 유효 시간 중 최장 상태를 사용하고 동률이면 high→caution→normal 우선으로 제안합니다. 무효 시간이 버킷 절반 이상이면 회색을 우선합니다. 툴팁에는 전체 구성과 유효 커버리지를 표시합니다. 부분 버킷의 분모는 실제 겹친 시간입니다.

요일·시간대는 선택한 IANA 시간대에 따라 자릅니다. 서버 저장은 UTC입니다. 조회 from은 포함, to는 제외입니다. DST로 반복되는 시간은 offset을 함께 유지한 뒤 표시 규칙을 정합니다. 원문 15°·30° 선은 해당 정책의 경계값으로 그립니다.

시간별 버킷은 현지 정각뿐 아니라 그 사이 UTC offset이 바뀌는 지점에서도 분리합니다.
전달된 알림은 시간이 속한 버킷에 넣고, 측정 종료 시각의 알림은 마지막 창의 활성 모드로 구분합니다.
창 없이 알림만 있는 버킷도 반환하며 유효 시간 0인 평균·비율은 null입니다.
같은 alert_id의 여러 채널은 한 번만 세고 교정 결과는 최초 전달 시각의 버킷에 기록합니다.

## 집계 예

동일 그룹에서 정상 40초, 주의 10초, 높은 신호 10초, 판단 불가 20초라면 경과 80초, 유효 60초, 기준 범위 비율은 66.67%입니다. 높은 신호 비율은 16.67%이며 무효 20초를 분모에 넣지 않습니다.

교정 완료가 3건이고 10·20·30초라면 평균 20초, 표본 수 3을 표시합니다. 다른 2건이 미확인이라도 0초를 추가하지 않습니다. 결과가 없는 경우 평균 null, 표본 수 0입니다.

## 일관성

1차 MVP는 backend가 승인된 창으로 집계하고 frontend가 그 응답을 표시합니다. 오프라인 중 새 통계는 계산하지 않으며 마지막 승인값과 전송 대기를 구분합니다. 반올림은 화면에서만 수행하며 저장 계산값을 반복 반올림하지 않습니다. 정책·모드 필터와 사용한 시간대를 응답에 포함합니다.

기록 화면은 서울 기준 오늘·7일·30일의 일별 또는 시간별 버킷을 표시합니다. 날짜가 바뀌거나 탭으로 복귀하면 조회 범위를 갱신합니다. 높은 신호 비율은 해당 버킷의 high 시간 / 유효 시간이며 분모가 0이면 `—`입니다. 모드와 출처를 배정할 수 없는 시간은 전체 방식에서만 별도로 표시합니다.
