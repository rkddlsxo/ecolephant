- 상태: completed

- 관련: REQ-013~016, AC-014/022, DEC-010.

## 완료 조건

1. 24시간 초과 세션과 빈 세션, 경계에 걸친 창을 합성 입력으로 재현한다.
2. API는 제한된 구간과 다음 조회 시작점을 반환하고 저장된 결과 범위 밖을 기록처럼 만들지 않는다.
3. 프론트는 필요한 구간을 더 불러오고 내보낼 때는 전체 구간을 가져온다. 실패·취소 시 부분 파일을 만들지 않는다.
4. 버킷마다 모든 창을 반복 조회하지 않는지 검사하고, API 명세·타입·하네스와 전체 회귀를 확인한다.

실제 데이터 규모·DynamoDB 성능과 운영 AWS는 별도 검증한다.

## 확인 결과

- SQLite·DynamoDB Local 백엔드 88개, 프론트 53개 검사를 통과했다.
- 희소 합성 기록의 24시간 지점을 브라우저에서 분할 조회했다. 파일 다운로드는 모의 검사로 확인했다.
- 분당 집계는 각 창을 한 번 훑고 걸친 버킷에 나눈다. DB는 여전히 해당 세션의 결과 전체를 읽는다.
