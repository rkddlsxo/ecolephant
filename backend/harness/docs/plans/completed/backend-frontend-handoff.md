- 범위: 백엔드의 로컬 API와 저장·집계, 간결한 프론트 화면, ML 연결 경계
- 관련 요구: REQ-001~018, AC-001/002/013/019~026, DEC-001/002/005~008/010

## 순서와 완료 조건

1. 하네스와 CI가 실제 Flask·SQLite의 세션, 중복, 종료, 소유권, 원본 차단 검사를 실행한다.
2. 백엔드 요청·저장·재시도·기록·집계를 검증하고 발견된 결함을 수정한다.
3. 기본 화면을 카메라, 테스트 측정, 기록으로 단순화한다. 합성 입력임을 명시한다.
4. ML은 연결 지점과 전달 계약만 남긴다. 영상·랜드마크·원시 모션은 서버로 보내지 않는다.
5. 프론트·백엔드 실행법과 ML 담당자의 입력·출력·검증 책임을 인계 문서에 기록한다.

## 검증 범위

하네스 전체 검사, API 통합 테스트, 프론트 테스트·정적 검사·빌드를 실행한다.
가능한 환경에서는 브라우저에서 테스트 측정과 기록 조회를 확인한다.
테스트 데이터는 임시 저장소에 두며 실측·운영 인증·배포 검증으로 표시하지 않는다.
2026-11-01 SQLite·DynamoDB Local 백엔드 검사 14개와 프론트 검사 31개가 통과했다.
브라우저에서 테스트 저장·기록 조회를 확인했다.
토큰 검사는 시험용 서명 키를 사용하며 실제 Cognito 인증과는 구분한다.
실제 카메라와 AirPods, 운영 인증·클라우드는 이번 검사에 포함하지 않았다.

## 제외 및 남은 결정

AI 모델·가중치와 실제 자세 추정, AirPods 도우미, 운영 로그인과 배포는 별도 작업이다.
실측 전 각도 판정, 의료 진단, 원본 전송과 미확정 정책 승인은 하지 않는다.
사용자에게 요청받은 최소 기능과 실제 검증 결과를 최종 문서에 남긴다.
