# DynamoDB 삭제·재시도 복구

- 상태: completed
- 완료일: 2026-11-01
- 생성일: 2026-11-01
- 관련: REQ-013/014/018, AC-019~026, DEC-006/008/010.

## 문제와 완료 조건

삭제가 일부 완료된 뒤 같은 이벤트 ID가 다른 세션에 재사용되면 이전 삭제 재시도가 새 식별자까지 지울 수 있다.
세션 시작 재시도의 조회 오류도 일시 장애를 삭제된 세션으로 바꾸지 않아야 한다.

1. 부분 삭제와 다른 소유자의 ID 재사용, 재시도 가능한 조회 오류를 먼저 재현한다.
2. 삭제는 현재 소유 세션의 식별자만 지우고 중간 실패 후에도 재시도할 수 있게 한다.
3. 일시적 저장 장애와 동시 쓰기 충돌을 보존하고 삭제된 세션만 삭제 오류로 변환한다.
4. 가상 데이터로 단위·DynamoDB Local 검사를 수행하고 실제 AWS 검증과 구분한다.

## 확인 결과

DynamoDB Local 3.3.2에서 부분 삭제·중간 실패 후 재시도와 다른 계정의 재사용 ID 보존을 확인했다.
일시 장애와 동시 쓰기 오류가 삭제 오류로 변환되지 않도록 수정했다. 실제 AWS 검증은 별도다.
