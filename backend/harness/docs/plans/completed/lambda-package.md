# Lambda 패키지 재생성

- 상태: completed
- 완료일: 2026-11-01
- 생성일: 2026-11-01
- 관련: REQ-013/018, AC-025/026, DEC-008/010.

## 문제와 완료 조건

기존 패키지 생성은 기존 폴더에 덮어써 삭제된 소스나 이전 의존성이 남을 수 있다.
환경 파일 미포함 주장도 복사 필터가 강제하지 않으므로 합성 파일로 검사한다.

1. 이전 코드 제거, 실패 시 기존 결과 보존, 소유권을 알 수 없는 폴더 보호를 먼저 검증한다.
2. 숨김 파일·환경 파일·심볼릭 링크를 제외하고 실행 코드와 계약만 복사한다.
3. 임시 위치에서 완성한 뒤 안전하게 교체하고 Python 3.12 Linux 패키지를 실제로 만든다.
4. 패키지 검사와 배포 전 한계를 문서·CI에 기록한다. AWS 접근이나 배포는 수행하지 않는다.

## 확인 결과

합성 재생성·실패 복구·기존 파일 보호·숨김 파일 제외 검사 4개가 통과했다.
Python 3.12 Linux 대상 패키지를 만들고 필수 코드·계약과 가상 계정의 CDK Python 앱 구성을 확인했다.
Linux에서 패키지를 실행하거나 실제 AWS 권한·배포를 검증한 것은 아니다.
