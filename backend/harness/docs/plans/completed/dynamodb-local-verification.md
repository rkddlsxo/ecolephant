# DynamoDB 로컬 저장 검증

- 상태: completed
- 완료일: 2026-11-01
- 생성일: 2026-11-01
- 관련: REQ-013/014/018, AC-019~026, DEC-005/006/008/010.

## 문제

백엔드 로컬 SQLite는 검증됐지만 클라우드 후보의 DynamoDB 어댑터는 실제 엔진으로 검사하지 않았다.
AWS 계정과 사용자 기록을 사용하지 않고 DynamoDB Local의 메모리 저장소로 같은 API 시나리오를 실행한다.

## 완료 조건

1. 테스트는 명시적인 루프백 주소와 임의의 테스트 테이블만 사용한다.
2. SQLite와 같은 응답 계약·중복·원본 차단·누락·집계·소유자 분리·삭제를 확인한다.
3. 오래된 버전의 쓰기가 최신 기록을 덮지 못하는지 확인하고 발견한 결함을 수정한다.
4. CI에 버전 고정된 DynamoDB Local을 연결하고 테스트가 빠지면 하네스가 실패한다.
5. 로컬 DB 텔레메트리를 끄고 실제 AWS 배포·권한·백업 검증과 결과를 구분한다.

## 확인 결과

2026-11-01 DynamoDB Local 3.3.2 메모리 모드에서 7개 시나리오가 통과했다.
빈 정렬 키 접두어 때문에 세션 조회가 실패하던 결함을 수정했다. 실제 AWS와 Docker Compose는 별도 검증이다.
