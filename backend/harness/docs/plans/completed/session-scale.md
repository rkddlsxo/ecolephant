# 장시간 기록의 저장과 조회

- 상태: completed
- 생성일: 2026-11-01
- 완료일: 2026-11-01
- 관련: REQ-013~016, AC-019~026, DEC-005/010.

## 완료 조건

1. 합성 긴 세션에서 상세·이벤트 조회와 반복 저장의 작업량을 재현한다.
2. 상세와 이벤트 조회는 필요한 기록만 읽고 소유권·삭제·일관성을 기존과 같이 보장한다.
3. 연속 측정 배치 저장은 기존 결과 전체의 반복 처리를 줄이고 재시도·충돌·정책·집계 결과를 유지한다.
4. 순서가 바뀐 요청과 과거 데이터에는 안전한 기존 경로를 제공한다.
5. SQLite와 DynamoDB Local의 응답·동시성·중복·집계 회귀를 확인한다.

실제 AWS 부하·비용과 실제 센서 정확도는 별도 검증한다.

## 확인 결과

- 합성 8시간 기록의 SQLite 상세·이벤트 조회는 약 100ms에서 약 1ms, 1창 추가 저장은 약 154ms에서 약 5ms로 줄었다. 특정 PC의 로컬 측정이다.
- 5초 배치 5,760회, 재시도 2회와 알림 16건을 포함한 합성 검사가 약 45초에 완료되었고 전체 기록 읽기는 18회였다.
- SQLite·DynamoDB Local 정규 143개 중 142개와 별도 8시간 검사 1개가 통과했다. 정규 검사에서 8시간 검사는 건너뛴다.
- 타임라인·통계·이벤트 저장과 예외 경로는 아직 세션 전체를 읽을 수 있다. 실제 AWS 부하 검증은 수행하지 않았다.
