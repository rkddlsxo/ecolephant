# 불변 정책 버전과 세션 호환

- 상태: completed
- 완료일: 2026-11-01
- 생성일: 2026-11-01
- 관련: REQ-006/013/014, AC-019~024, DEC-002/004/007/008.

## 문제

현재 서버는 예시 정책 하나를 전역 값으로 사용하므로 실측 검증 후 새 정책을 더하거나 기존 세션을 안전하게 유지하기 어렵다.
실제 모델·특징·각도 계산이나 승인 수치를 임의로 만들지 않고 백엔드의 정책 버전 경계를 준비한다.

## 완료 조건

1. 동일 ID의 내용 변경 거부, 서로 다른 정책 분리, 기존 세션 재시도와 이전 데이터 호환 검사를 먼저 작성한다.
2. 정책 등록·조회와 세션별 적용 기준이 버전별로 일관되며 비승인 실측은 계속 차단된다.
3. SQLite와 DynamoDB Local에서 중복·동시 쓰기·삭제·업데이트 후 재시도를 확인한다.
4. 정책 파일 검증, OpenAPI·하네스·인계 문서를 갱신하고 전체 테스트를 실행한다.

실제 측정 정책의 기준·모델 특성과 승인은 ML·팀 검증이 필요하며 이 작업에서 임의로 확정하지 않는다.

## 구현과 확인

세션 snapshot과 불변 정책 등록, 기존 초안 복원, 정책별 판정·알림을 추가했다.
SQLite와 DynamoDB Local의 합성 입력으로 버전·재시도·동시 등록 검사를 실행한다.
프론트의 새 정책 전달, 철회 절차, 실측 검증과 실제 AWS는 별도 작업이다.
