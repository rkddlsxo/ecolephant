# 긴 타임라인 조회 최적화

- 상태: completed
- 생성일: 2026-11-01
- 완료일: 2026-11-01
- 관련: REQ-013~016, AC-014/022, DEC-005/010.

## 완료 조건

1. 긴 합성 세션의 타임라인이 현재 전체 결과를 읽는 사례를 재현한다.
2. 연속 창과 1분 요약을 같은 트랜잭션에 저장하고, 분 단위 조회는 필요한 요약만 읽는다.
3. 비정렬 범위·이전 기록·누락된 요약은 원래 결과로 계산하여 부정확한 응답을 막는다.
4. 순서 변경·중복·경계 알림·동시 쓰기·삭제 후 데이터 정리를 두 저장소에서 검사한다.
5. 기존 API 응답과 전체 재계산이 일치하며 정규·장시간 검사와 하네스를 통과한다.

요약은 파생 결과만 포함한다. 실제 AWS 부하와 기기 성능은 별도 검증한다.

## 검증 결과

- SQLite·DynamoDB Local 정규 검사 178개 중 177개와 별도 8시간 합성 검사 1개가 통과했다.
- 8시간 분량의 분별 요약 480개와 마지막 2시간 결과를 원본 없이 조회했다.
- 별도 SQLite 합성 비교에서 2시간 조회는 원본 약 112ms, 요약 약 3ms였으며 응답은 같았다.
- 이전 SQLite 버전으로 되돌릴 때 요약 삭제 경로를 포함하는 마이그레이션이 필요하다.
