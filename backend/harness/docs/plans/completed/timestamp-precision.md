# API 시각 정밀도

- 상태: completed
- 생성일: 2026-11-01
- 완료일: 2026-11-01
- 관련: REQ-013~016, AC-019/022/024, DEC-010.

## 완료 조건

1. 세션 시작·종료와 기간 조회에서 밀리초 미만 값이 잘려 허용되는 사례를 재현한다.
2. 시간대가 있는 RFC3339 시각 중 밀리초 단위로 정확히 표현되는 값만 받는다. 뒤에 붙은 0은 허용한다.
3. 잘못된 시각은 데이터 변경 전에 422로 거부하고 기존 밀리초 요청과 저장 기록은 유지한다.
4. OpenAPI·정상/거부 예시·프론트 생성 타입·하네스와 저장소별 회귀 검사를 확인한다.

계약 강화이므로 기존 연동자는 밀리초보다 정밀한 시각 전송을 수정해야 한다.

## 확인 결과

- 변경 전 시작·종료·기간 조회가 소수점 아래 값을 잘라 받던 사례를 재현했다.
- API 명세와 파서는 동일한 정규식을 사용하고 윤초 60초를 거부한다.
- SQLite·DynamoDB Local 백엔드 102개와 프론트 53개 검사를 통과했다.
