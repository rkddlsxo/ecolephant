# 실제 센서와 운영 연결

- 상태: planned
- 생성일: 2026-10-17
- 관련: REQ-002, REQ-004, REQ-005, REQ-006, REQ-013, REQ-018.

## 남은 입력

포즈 모델·각도 매핑, AirPods 도우미 플랫폼/축, 디자인 시스템 패키지, 운영 IAM·호스팅·인증·보관 기간.

## 작업 순서

1. 센서 출시 범위·AI 모델을 선택하고 실제 입력 어댑터를 연결합니다.
2. 기준 보정과 품질·시간 정렬을 실측합니다. 예시 각도를 실제 센서 출력에 재사용하지 않습니다.
3. 인수 시나리오와 계약·집계·재시도 검증을 실행해 증거를 연결합니다.
4. Docker/DynamoDB·Cognito·CDK synth, 보관·삭제·오프라인 동작을 확인합니다.
5. 담당자 승인 아래 Amplify와 운영 API를 연결합니다.

현황은 [MVP 상태](../../../../docs/development/mvp-status.md), 결정은 [DEC](../../../../docs/decisions/open-decisions.md)를 따릅니다.
